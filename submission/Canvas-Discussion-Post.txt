Subject: Feedback on Fearless Conspiracy

My game is Fearless Conspiracy, a Rust game inspired by Town of Salem for 3-9 players. Town tries to find the Mafia, while the Mafia tries to eliminate Town. Players talk and vote during the day and use private abilities at night.

It uses Unix-domain stream sockets with JSON messages. The communications library is all in src/comm.rs and supports private replies, group chat, and broadcasts. Reader and writer threads handle multiple players at once.

For this project, I focused on isolation. In a controlled test, a Town player could watch server thread activity to figure out who was receiving Mafia messages without reading the messages themselves. I added separate Linux accounts and hidepid=2 to block access to that metadata, plus cgroup limits to contain resource abuse. Protection is now the default, and shutdown restores the previous settings. There is also a recovery option if cleanup gets interrupted.

I'd like feedback on a few things:

- Can you find another way to figure out who the Mafia is through process information or permissions?
- Could disconnects, bad messages, or resource abuse crash the game or bypass its limits?
- Is the communications API easy to follow, and does message delivery work as expected?

The code and setup instructions are on GitHub: https://github.com/mbialecki3/fearless-conspiracy

Protected mode needs a dedicated Ubuntu/systemd VM with cgroup v2. If you try it, please share your steps and what happened.
